# EEMD-RL NCU Campus

An interactive campus energy-management demonstration combining a semantic
building model, timetable-driven occupancy profiles, and reinforcement-learning
research results.

## Features

- Animated introduction and campus branding
- Interactive four-floor, 157-space building model
- Room occupancy, temperature, energy and safety visualisations
- Seasonal and controller comparison views
- Seven-day simulation timeline
- Future implementation roadmap

## Requirements

- Node.js 24
- pnpm 11.25.0
- A browser with WebGL support
